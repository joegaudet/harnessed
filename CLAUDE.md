## Keep the website in sync

The marketing site at `docs/site/` is hand-written HTML, not generated. When a
change touches anything it shows (runners, drivers, UI frameworks, conformance
status, packages, or an API used in one of its snippets), update `docs/site/` in
the same PR. The checklist is **The website** in CONTRIBUTING.md; follow it, and
tick the Website box in the PR template.
