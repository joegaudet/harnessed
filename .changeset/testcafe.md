New package `@harnessed-ts/testcafe`: a TestCafe driver. `testcafe(t)` builds the env; lookups run the shared resolver inside the page through TestCafe client functions, actions go through TestCafe, and actions inside a frame switch into each iframe and back. Pages can navigate, and the driver passes the full conformance catalog.
