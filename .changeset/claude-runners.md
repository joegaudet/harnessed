`install` detects the repo's test runners — Ember, Cypress, WebdriverIO, TestCafe, Puppeteer, Playwright, Vitest browser mode, Testing Library, and the Gherkin runners — from its dependencies and the config files each leaves behind. The skill gains a generated "Your runners" section showing how a test in that repo builds the env and asserts, and a worked example is written per detected runner.
